# Roadmap — Time Tracking Metrics

## v0.1 — Basic tracking (current project only)

Outcomes

- Active time tracking inside VS Code
- Idle auto-pause + manual pause/resume
- Local session summaries (local-only mode supported)

Notes

- Sync may be disabled by default until Phase 7 is ready.

---

## v1.0 — Multi-project tracking

Outcomes

- DevOnboarder ingest + personal dashboard
- Project rollups across repos/workspaces
- Local-first sync queue + retention policy

---

## v1.5 — Language / file-type breakdown

Outcomes

- Language breakdown charts
- File type categories (code/docs/config) without file names
- Optional hashed file references (Mode B opt-in)

---

## v2.0 — Team analytics

Outcomes

- Team-level aggregates
- Trend reports (weekly/monthly)
- Hardened role-based access controls

Guardrail

- No default “rank by hours” culture features.

---

## v3.0 — Public developer profiles (opt-in)

Outcomes

- Opt-in public profiles (publishable aggregates only)
- Public API with versioned contract
- Clear separation of internal domains vs public hostnames
